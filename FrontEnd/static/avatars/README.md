# Avatar assets

Save local SVG portraits in this directory. Use the character name in lowercase without accents and separate words with hyphens, for example `Bình` uses `binh.svg`. Refresh the game after adding files. The UI shows the character's initials until the portrait loads and keeps the initials if the image is unavailable.
The character portraits are currently using the UI's initials fallback. The required pre-downloaded DiceBear Open Peeps SVG files could not be fetched because this environment cannot resolve `api.dicebear.com`. No solution or unrevealed clue data is stored here.

Required source for completion: Open Peeps by Pablo Stanley, CC0 1.0, https://www.openpeeps.com/ (via DiceBear: https://www.dicebear.com/styles/open-peeps/).
